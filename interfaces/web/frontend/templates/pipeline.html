GUIA DO COMPILADOR

Como funciona o pipeline

O MiniPar transforma seu programa em etapas para que você possa acompanhar e entender cada resultado.

Voltar ao painelAbrir editor →
01

Código-fonte

Você escreve ou carrega um programa MiniPar no editor. Esta é a entrada usada em todas as etapas seguintes.

02

Tokens

O analisador léxico separa o texto em unidades, como palavras-chave, identificadores, operadores e valores.

03

AST

O analisador sintático organiza os tokens em uma árvore que representa a estrutura do programa.

04

Símbolos

A análise semântica verifica o significado do código e registra variáveis, funções, tipos e escopos.

05

TAC

O programa é convertido em código de três endereços, uma forma intermediária simples para analisar e otimizar.

06

C++

O gerador traduz o TAC para C++, preparando o programa que será compilado pelo ambiente.

07

Execução

O MiniPar executa o programa compilado e mostra a saída, os erros e o tempo medido.
