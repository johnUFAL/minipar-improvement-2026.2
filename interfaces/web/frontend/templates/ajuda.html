GUIA RÁPIDO

Ajuda do MiniPar

Como escrever, compilar, executar e baixar programas MiniPar, inclusive em dois computadores.

Como funciona o pipelineAbrir editor →

1. Usando o editor

  • Exemplo: escolha um programa pronto na lista; os pares cliente/servidor ficam agrupados.
  • Compilar e executar (Ctrl + Enter): gera o executável e roda o programa. Use as fases Código, Tokens, AST, Símbolos, TAC, C++ e Execução para acompanhar cada etapa.
  • TAC O0–O3: nível de otimização aplicado ao código de três endereços antes de gerar o C++.
  • Baixar .exe: compila o programa atual e baixa o executável para rodar fora da interface.
  • Entradas do programa: uma linha por input().

2. Linguagem

# comentário
class Contador {
    n = 0
    def init(inicio) { this.n = inicio }
    def passo() { this.n = this.n + 1 }
}

SEQ
    var c = new Contador(0)
    var i = 0
    while i < 3:
        c.passo()
        i = i + 1
    do:
        i = i - 1
    while i > 0
    for x in range(3):
        print(x)
    print("n =", c.n)

Tipos: bool, int, float, string, list. Laços: while, do … while e for … in. Blocos usam indentação ou chaves.

3. Paralelismo

PAR
    fatorial()
    fibonacci()

fork a em core(1):
    trabalho_a()
fork b em host("computador_2"):
    trabalho_b()
join a, b

PAR executa ramos em threads sem memória compartilhada; fork distribui subtarefas em núcleos (core) ou computadores (host) e join espera o término.

4. Canais e dois computadores

c_channel dados computador_1 computador_2

dados.send("+", 2.0, 3.0, 0.0)
dados.receive(status, resultado, a, b)
  1. Abra Conexão, crie ou escolha um hub e entre em uma sala.
  2. Abra o programa cliente no editor e clique em executar: o outro lado recebe um convite.
  3. Quando aceitar, os dois vão ao editor, cada um com o seu programa, e o terminal de execução aparece.

O chip no topo mostra se você está em um hub e em qual sala. Em redes virtuais (Radmin, Hamachi), libere as portas do hub no firewall.

5. Entendendo os erros

Os diagnósticos informam a fase (léxica, sintática ou semântica), a linha e a coluna. Corrija o primeiro erro e compile de novo: erros seguintes costumam ser consequência dele. Os exemplos ficam em programas_teste/.
